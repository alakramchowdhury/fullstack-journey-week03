# Week 3 · Arrays, objects, the DOM, events and closures

Complete, commented code for every day of Week 3. Each `dayNN` folder is a **full, runnable snapshot** at the end of that day.

**Week output:** a page with three interactive widgets (tabs, an accessible modal dialog and a to-do list that remembers your tasks), built with plain JavaScript and deployed, plus 6 LeetCode problems.

## How to use this folder

1. **Try first, then compare.** Files ending in `-starter.js` are yours to fill in; `-solutions.js` files are the answers.
2. Open every `.html` file with **Live Server** (right-click → Open with Live Server). Practice pages show PASS / FAIL on the page and in the Console (**F12**).
3. From Day 20 the widgets use **ES modules**, which only work through a web server (Live Server or Vercel), not by double-clicking the file.

## Setup

Open this folder in VS Code (**File → Open Folder…**) and accept the recommended extensions (Live Server, Prettier).
